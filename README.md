# sblog

بنية موقع إخباري عربي ثابتة ومنظمة، مع فصل الواجهة والبيانات والمقالات والصفحات القانونية وملفات SEO.

## Structure

- `index.html` — الصفحة الرئيسية
- `assets/` — CSS وJavaScript
- `data/posts.json` — مصدر بيانات الأخبار
- `posts/` — صفحات المقالات المستقلة
- `pages/` — الصفحات القانونية والمعلوماتية
- `sitemap.xml` — خريطة الموقع
- `robots.txt` — تعليمات محركات البحث
- `404.html` — صفحة الخطأ

يعمل المشروع على GitHub Pages دون خادم تقليدي؛ طبقة البيانات المحلية (`data/posts.json`) تمثل مصدر المحتوى في النسخة الثابتة.
